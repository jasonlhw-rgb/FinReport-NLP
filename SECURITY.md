# Security Policy

## Supported versions

Security fixes are accepted for the latest `main` branch of FinReport-NLP.

## Reporting a vulnerability

If you discover a security issue (for example accidental exposure of credentials,
unsafe deserialization, or path traversal in file utilities), please **do not**
open a public GitHub issue.

Instead, contact the repository owner privately via GitHub Security Advisories
or a private email / message linked on the owner's profile.

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact

We will acknowledge the report and work on a fix as soon as reasonably possible.

## Please do not commit

- API keys, cookies, tokens, passwords
- Private financial corpora you are not authorized to redistribute
- Personal identifying information
